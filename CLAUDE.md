## Commands

Package manager: **Bun** (`bun.lockb` present, `bunfig.toml` configured). `npm` also works since this is a standard Node project.

- `bun dev` — start Vite dev server (defaults to port 8080; falls back to next free port)
- `bun run build` — production build (Cloudflare Workers target)
- `bun run build:dev` — build with development mode optimizations
- `bun run preview` — preview the production build locally
- `bun run lint` — ESLint over the whole repo
- `bun run format` — Prettier write across the repo

No test framework is configured.

## Architecture

This is a **TanStack Start** marketing site (Movements Consulting) running on **Vite** and deployed to **Cloudflare Workers** (`wrangler.jsonc`, `main: "@tanstack/react-start/server-entry"`).

### Vite config is locked

`vite.config.ts` is a single line: `defineConfig()` from `@lovable.dev/vite-tanstack-config`. That preset already wires up:

- `tanstackStart`, `viteReact`, `tailwindcss`, `tsConfigPaths`
- Cloudflare plugin (build-only) and componentTagger (dev-only)
- `VITE_*` env injection, the `@/` path alias, React/TanStack dedupe
- Dev server port/host/strictPort and sandbox detection

**Do not add these plugins manually** — duplicates will break the app. If you need to extend Vite, use `defineConfig({ vite: { ... } })`.

### Routing

File-based routing via TanStack Router. Routes live in `src/routes/*.tsx`. `src/routeTree.gen.ts` is **auto-generated by the router plugin** — never edit it; it is excluded from lint and re-emitted on dev/build.

- `src/routes/__root.tsx` — root layout: `<HeadContent>`, `<Scripts>`, sticky header, `SidebarProvider`, `<AppSidebar>`, `<Outlet>`, footer. Defines site-wide `<head>` meta (OG/Twitter tags, Google Fonts).
- `src/router.tsx` — `getRouter()` factory; sets `defaultErrorComponent` and `scrollRestoration: true`.
- `defaultOpen={false}` on `SidebarProvider` means the sidebar is **collapsed by default**; toggled via `<SidebarTrigger>` in the header.

### Component layout

- `src/components/ui/` — **shadcn/ui** (style: `new-york`, base color: `slate`, icon library: `lucide`). Configured in `components.json`. Don't hand-write replacements for these primitives; extend or compose them.
- `src/components/AppSidebar.tsx` — the project-specific sidebar that wraps `ui/sidebar.tsx`.
- `src/hooks/` and `src/lib/utils.ts` — `cn()` helper lives there.
- Path aliases (set in `tsconfig.json` + `components.json`): `@/components`, `@/components/ui`, `@/lib`, `@/hooks`, and `@/` for `src/`.

### Design system

Defined in `src/styles.css` using **Tailwind v4** (`@theme inline` block) over CSS custom properties. Two important rules:

1. **All colors MUST be `oklch()`** — see the comment block at the top of `styles.css`. The palette is warm cream background, deep forest green primary, earth brown accent, dark brown sidebar.
2. To add a semantic color: define it under both `:root` and `.dark`, then register it under `@theme inline` as `--color-<name>: var(--<name>)` so Tailwind generates `bg-<name>` / `text-<name>` utilities.

Custom tokens beyond the standard shadcn set: `--gradient-hero` (used by the home hero), `--shadow-elegant`, and a full sidebar palette (`--sidebar*`).

### Deployment

Cloudflare Workers via Wrangler. `wrangler.jsonc` sets `compatibility_flags: ["nodejs_compat"]` and points `main` at TanStack Start's server entry — the Vite build emits the Worker bundle.
